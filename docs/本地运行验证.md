## 启动与停止

在项目根目录的 PowerShell 中运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 app.py
```

访问 <http://127.0.0.1:5000>。前台运行时，在该终端按 `Ctrl+C` 停止。
无需激活虚拟环境，也无需重新生成向量或重新上传数据。

本次验证服务在隐藏后台窗口运行，PID 记录在 `data/local_setup/server_pid.json`。
停止本次后台服务后，才能用上述命令占用同一个端口：

```powershell
$serverInfo = Get-Content -Raw data\local_setup\server_pid.json | ConvertFrom-Json
$serverProcess = Get-CimInstance Win32_Process -Filter "ProcessId = $($serverInfo.pid)"
if ($serverProcess -and $serverProcess.ExecutablePath -eq $serverInfo.python -and
    $serverProcess.CommandLine -like "*$($serverInfo.entry)*") {
    taskkill /PID $serverInfo.pid /T /F
}
```

使用 `/T` 同时结束虚拟环境启动器及其 Python 子进程，避免只停启动器后端口仍被占用。
验证结束后已切回正常的 `app.py`，没有保留运行时 API 诊断包装。
